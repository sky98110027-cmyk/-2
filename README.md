# 결 (Gyeol)

영상 한 편의 결을 뜯어서 스킬로 만들어 둡니다.
그다음부터는 주제만 바꿔 넣어도 같은 결로 나옵니다.

말로 시키면 됩니다. 터미널은 안 열어도 됩니다.

---

## 쓰는 법

화면 맨 위 칸에 평소 말하듯 적으면 됩니다.

### 결 뽑기

영상 주소를 붙여넣습니다. 그것만으로 됩니다.

```
https://www.youtube.com/watch?v=... 이 영상 결 뽑아줘
```

화면 얘기를 곁들이면 더 정확해집니다.

```
https://youtu.be/... 결 뽑아줘. 화면은 세피아 톤이고 자막은 아래 한 줄이야
```

마음에 들면 저장합니다.

```
이 결 저장해줘
```

### 받아둔 파일로 뽑기

주소가 없어도 됩니다. 화면 아래 칸에 파일을 끌어다 놓으세요.

| 넣을 수 있는 것 | 비고 |
| --- | --- |
| `.txt` `.md` | 직접 쓰신 대본. 이게 가장 정확합니다 |
| `.srt` `.vtt` `.ass` | 자막 파일. cp949 로 된 옛날 자막도 읽습니다 |
| `.mp4` `.mov` `.mkv` 등 | 자막이 박혀 있으면 꺼냅니다 ([ffmpeg](https://ffmpeg.org) 필요) |

### 대본 만들기

```
담담한 증언체로 김좌진과 청산리 8분짜리 써줘
```

### 한 번에 여러 편

동시에 돌아갑니다. 세 편이 한 편 만드는 시간에 나옵니다.

```
홍범도, 김좌진, 안중근 세 개 한 번에 써줘
```

### 폴더 이름 직접 짓기

```
오늘 폴더는 독립군 3부작으로 하고 홍범도, 김좌진 두 개 써줘
```

`독립군 3부작 - 홍범도`, `독립군 3부작 - 김좌진` 이렇게 갈라서 담깁니다.

### 고치기

```
자막 더 크게 하고 노란색으로 바꿔줘
자막을 화면 가운데로 올려줘
세로 쇼츠 비율로 바꿔줘
3번 장면 나레이션이 기니까 줄여줘
```

**자막 글꼴, 색, 위치, 크기는 영상을 다시 뽑지 않아도 됩니다.**
미리보기에서 바로 보이고, 자막만 다시 입히면 끝입니다.

그림 자체가 바뀌는 것만 다시 뽑으면 됩니다.
그럴 때는 몇 컷을 다시 뽑아야 하는지 먼저 알려드립니다.

### 모르는 게 있으면 그냥 물어보세요

클로드만 연결돼 있으면 사용법도 직접 답해줍니다.

```
이거 어떻게 쓰는 거야?
자막 색도 바꿀 수 있어?
영상 만들려면 뭐가 더 있어야 해?
```

## 연결

**연결** 탭에서 쓸 도구를 붙입니다.

### 클로드가 1순위입니다

이게 없으면 아무것도 안 돕니다.
[console.anthropic.com](https://console.anthropic.com) 에서 키를 만들어 넣으세요.
넣고 **연결 확인**을 누르면 진짜 되는지 찔러봅니다.

### 나머지는 있으면 좋은 것들

| 도구 | 하는 일 | 없으면 |
| --- | --- | --- |
| 힉스필드 / 톱뷰 | 장면 그림과 영상 | 영문 프롬프트가 나오니 다른 도구에 붙여넣으면 됩니다 |
| 일레븐랩스 | 나레이션 목소리 | 원고를 직접 읽어 녹음하시면 됩니다 |
| [ffmpeg](https://ffmpeg.org) | 자막 굽기, 영상에서 자막 꺼내기 | 편집 프로그램에서 직접 붙이시면 됩니다 |

**연결** 탭 맨 위에 지금 어디까지 되는지 점검표가 뜹니다.
안 되는 단계마다 무엇이 필요한지, 없어도 되는 길은 무엇인지 같이 나옵니다.

### MCP 붙이기

MCP를 등록해두면 이 폴더에서 클로드 코드를 켤 때 그 도구가 같이 붙습니다.

주소는 각 회사 설정 페이지에서 받아 붙여넣으시면 됩니다.
회사마다 다르고 자주 바뀌어서 여기에 미리 적어두지 않았습니다.

### 키는 어디에 있습니까

이 폴더의 `.env` 파일입니다.
남이 못 읽게 잠가둡니다. 깃에도 안 올라갑니다.
화면에는 끝 네 자리만 보입니다.

**다만 그 파일 자체를 남에게 보내지는 마세요.** 키가 그대로 적혀 있습니다.

## 나오는 것

| 파일 | 내용 |
| --- | --- |
| `script.txt` | 성우가 바로 읽을 나레이션 원고 |
| `script.json` | 전체 데이터 |
| `caption.ass.txt` | 자막 굽는 설정. 영상은 그대로 두고 자막만 갈아끼울 때 씁니다 |

`production_order` 에는 장면마다 영문 프롬프트가 들어 있습니다.
힉스필드, 톱뷰 같은 도구에 그대로 넣으면 됩니다.

저장 폴더는 **설정** 탭에서 바꿀 수 있습니다.
바탕화면처럼 찾기 쉬운 곳으로 옮기셔도 됩니다.

## 만들어진 스킬은 앱 밖에서도 돕니다

저장한 결은 `SKILL.md` 라는 파일로도 만들어집니다.
이 파일이 `.claude/skills/` 에 같이 깔립니다.

클로드 코드나 클로드 데스크톱에서 "그 결로 만들어줘" 하면
대본부터 영상 생성 도구 호출까지 한 줄로 이어집니다.

앱은 결을 보관하는 창고, 클로드는 실제 작업장인 셈입니다.

## 터미널로 쓰기 (익숙하신 분만)

```bash
cd src

python -m gyeol 결뽑기 "https://youtu.be/..." --저장
python -m gyeol 결뽑기 --파일 받아둔영상.mp4 --저장
python -m gyeol 목록
python -m gyeol 대본 gyeol-20260920-130000 "김좌진과 청산리" --분 8 --폴더 "독립군 3부작"
python -m gyeol 서버
```

## 못 하는 것

솔직히 적어둡니다.

- **영상에서 말을 글로 옮기지 못합니다.** 자막이 없는 영상은 대본을 직접 넣어주셔야 합니다.
- **영상을 통째로 보지는 못합니다.** ffmpeg가 있으면 장면 바뀌는 지점마다 한 장씩 뽑아서 봅니다.
  구도, 색감, 화면 위 글씨, 밈 캐릭터 자리까지 그 한 장으로 읽습니다. 모든 프레임은 아닙니다.
- **환경음이 무슨 소리인지는 못 듣습니다.** 말 없는 구간이 침묵인지 음악만인지는 잽니다.
- **장면 그림을 직접 그리지 못합니다.** 영문 프롬프트까지 만들고, 그림은 힉스필드나 톱뷰가 뽑습니다.
  그림이 모이면 ffmpeg로 묶어 mp4를 만듭니다.

## 설정

| 환경변수 | 하는 일 | 기본값 |
| --- | --- | --- |
| `ANTHROPIC_API_KEY` | 클로드 API 키 (필수) | 시작할 때 물어봄 |
| `GYEOL_MODEL` | 쓸 모델 | `claude-opus-5` |
| `GYEOL_AUDIENCE` | 시청 타깃 | `40~60대 시니어 시청자` |
| `GYEOL_DATA_DIR` | 저장 위치 | `data/` |
| `GYEOL_PORT` | 쓸 포트 | `8000` |
